# UK Bat Study & Records

A single-file, offline web app for studying and recording the UK's bat species.

Created by Mitchell Steele.

## What it is

- Study profiles for all 18 UK bat species (from the project ID sheets), with drawings, photographs where available, official GB Red List conservation status, and ecology.
- A guided identification key.
- A field-record feature with photo capture (metadata stripped), what3words location, and export.
- Downloads of the original ID sheets as illustrated PDFs.
- Legislation and Guidance reference sections with search.

It is an identification aid, not a determination. All UK bats are European Protected
Species; handling or disturbing them requires an appropriate licence.

## How to use it

- Open `index.html` in any web browser (phone, tablet or computer).
- It works fully offline. An internet connection is only needed to open external
  links (legislation, guidance, what3words).

## The files

- `index.html` — the current app (this is the one to open).
- The version number is shown in the browser tab and in the bottom-right corner of
  the app's cover screen.

## Updating to a new version

1. Click **Add file → Upload files** in this repository.
2. Drag in the new `index.html` (overwriting the old one).
3. Add a short commit message (e.g. "Update to v3.7") and click **Commit changes**.

GitHub keeps every version in the commit history.

## Optional: a live web link (GitHub Pages)

To open the app from a web link (and "Add to Home Screen" like an app):

- GitHub Pages serves `index.html` automatically.
- On the **free** plan, Pages requires the repository to be **public**.
- To keep the repository **private** and use Pages, a paid GitHub plan is needed.
- Enable it under **Settings → Pages**, choose the `main` branch and root folder, save,
  and GitHub provides the link after a minute.
